## 📋 პროექტის შესახებ

**MediBook** არის React-ზე დაფუძნებული სამედიცინო ვებაპლიკაცია, რომელიც ამარტივებს ექიმების მოძიებისა და სამედიცინო ვიზიტების ონლაინ დაჯავშნის პროცესს.

პლატფორმა საშუალებას აძლევს პაციენტებს გაეცნონ ექიმების სპეციალობებსა და გამოცდილებას, შეამოწმონ თავისუფალი დროები და დაჯავშნონ ვიზიტი. ადმინისტრატორისთვის გათვალისწინებულია ექიმების მონაცემების მართვა, ხოლო ექიმისთვის — საკუთარი ვიზიტების კონტროლი.

პროექტის მიზანია სამედიცინო მომსახურების ციფრული ხელმისაწვდომობის გაუმჯობესება, პაციენტების დროის დაზოგვა და ადმინისტრაციული პროცესების გამარტივება.

## ✨ ძირითადი ფუნქციონალი

### 🔐 ავტორიზაცია და მომხმარებლის როლები

- მომხმარებლის რეგისტრაცია და სისტემაში შესვლა;
- JWT Token-ზე დაფუძნებული ავტორიზაცია;
- პაროლების უსაფრთხო ჰეშირება `bcryptjs`-ით;
- მომხმარებლის როლები: `patient`, `doctor`, `admin`;
- Backend API-ზე დაცული Endpoint-ები;
- მომხმარებლის სესიის მონაცემების შენახვა `localStorage`-ში.

### 👨‍⚕️ ექიმების კატალოგი

- ექიმების სიის ჩვენება;
- ექიმების სახელის, სპეციალობისა და გამოცდილების წარმოდგენა;
- ექიმების მონაცემების მიღება Backend API-დან;
- ძიების მდგომარეობის მართვა Zustand Store-ით;
- მონაცემების ჩატვირთვისა და შეცდომების დამუშავება.

### 🗂️ მონაცემთა მართვა (CRUD)

ექიმების Backend API უზრუნველყოფს სრულ CRUD ფუნქციონალს:

- **Create:** ახალი ექიმის დამატება;
- **Read:** ექიმების სიისა და დეტალების მიღება;
- **Update:** ექიმის მონაცემების განახლება;
- **Delete:** ექიმის წაშლა.

მონაცემები ინახება SQLite მონაცემთა ბაზაში, ხოლო ცვლილებების განხორციელების უფლება შეზღუდულია ადმინისტრატორის როლით.

### 📅 ვიზიტების დაჯავშნა

- თავისუფალი დროების შემოწმების API;
- პაციენტის მიერ ვიზიტის შექმნა;
- ვიზიტების მონაცემების შენახვა SQLite-ში;
- საკუთარი ვიზიტების მიღება ავტორიზებული მომხმარებლისთვის;
- ერთი ექიმის ერთსა და იმავე დროს ორმაგი დაჯავშნის დაბლოკვა.

### 🛡️ ვალიდაცია და მდგრადობა

- ფორმის მონაცემების შემოწმება;
- Backend ვალიდაცია `Zod`-ით;
- შეცდომების დამუშავება `try/catch` კონსტრუქციით;
- API შეცდომების შეტყობინებები;
- ავტორიზაციის ფორმაში გაგზავნის ღილაკის დაბლოკვა მოთხოვნის დამუშავებისას;
- HTTP სტატუსების გამოყენება შეცდომების აღსანიშნავად.

### 📱 ადაპტური ინტერფეისი

ინტერფეისი შექმნილია სხვადასხვა ზომის ეკრანზე გამოსაყენებლად:

- მობილური მოწყობილობები;
- პლანშეტები;
- დესკტოპ კომპიუტერები.

დიზაინისთვის გამოყენებულია CSS და React კომპონენტური არქიტექტურა.

## ⚙️ ლოკალურად გაშვების ინსტრუქცია

### 1. რეპოზიტორიის კლონირება

```bash
git clone https://github.com/takkh19/MediBook.git
cd MediBook
```

### 2. Frontend-ის პაკეტების ინსტალაცია

```bash
npm install
```

### 3. Backend-ის პაკეტების ინსტალაცია

```bash
cd server
npm install
```

### 4. Backend-ის გარემოს ცვლადების გამართვა

`server` საქაღალდეში შექმენით `.env` ფაილი:

```env
PORT=3001
CLIENT_ORIGIN=http://localhost:5173
JWT_SECRET=replace-with-a-long-random-secret-at-least-32-characters
```

`JWT_SECRET` შეცვალეთ საკუთარი შემთხვევითი, უსაფრთხო მნიშვნელობით.

### 5. Backend-ის გაშვება

`server` საქაღალდეში:

```bash
npm run dev
```

Backend ხელმისაწვდომი იქნება მისამართზე:

http://localhost:3001/api/health

### 6. Frontend-ის გარემოს ცვლადების გამართვა

პროექტის მთავარ საქაღალდეში შექმენით `.env.local`:

```env
VITE_API_URL=http://localhost:3001
```

### 7. Frontend-ის გაშვება

გახსენით მეორე ტერმინალი და პროექტის მთავარ საქაღალდეში გაუშვით:

```bash
npm run dev
```

გახსენით ბრაუზერში:

http://localhost:5173/MediBook/

**მნიშვნელოვანია:** სრული ფუნქციონალისთვის საჭიროა Frontend-ისა და Backend-ის ერთდროულად გაშვება.

GitHub Pages-ზე განთავსებულია Frontend. Backend-ის საჯარო გამოყენებისთვის საჭიროა მისი ცალკე სერვერზე განთავსება.
